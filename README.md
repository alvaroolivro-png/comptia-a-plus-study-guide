# CompTIA A+ Accessible Study Guide

Static, free study aid for CompTIA A+ V15 Core 1 (220-1201) and Core 2 (220-1202). The guide uses original paraphrased notes, direct links to free resources, and original interactive quizzes. It is not affiliated with CompTIA or Professor Messer.

## Preview locally

Open `index.html` in a browser. No build tools, accounts, cookies, or third-party JavaScript are required.

## Accessibility features

- Semantic landmarks, ordered headings, and a skip link.
- Keyboard-visible focus, labeled radio controls grouped by fieldset/legend, and live quiz status messages.
- Responsive reflow, readable contrast, reduced-motion support, and print styles.
- No information is conveyed only by color; quiz results include text explanations.

The page is designed with WCAG 2.2 guidance in mind; it has not been independently certified as conformant. Please report access barriers with browser and assistive-technology details.

## Exam alignment and sources

Use CompTIA's current objectives as the authoritative checklist. Core 1 and Core 2 must be the same series. Professor Messer's free course indexes provide the video sequence for each core. Microsoft Learn is included as an optional free product-training source.
